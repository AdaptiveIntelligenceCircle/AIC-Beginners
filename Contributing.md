# Contributing to AIC

Thank you for your interest in contributing to Adaptive Intelligence Circle.

## Principles
- Contributions must align with the covenant: ethical-from-kernel, zero-donation, zero-data.
- Transparency and clarity are valued over speed.
- Respect the Code of Conduct.

## How to Contribute
1. Fork the repository.
2. Create a branch for your changes.
3. Submit a Pull Request with a clear description.
4. Ensure your code follows our style guidelines and passes tests.

## Issues
- Use GitHub Issues to report bugs or suggest improvements.
- Provide context and reproducible steps when reporting.

## Recognition
- Contributors are acknowledged in release notes.
- No financial donations are accepted; contributions are purely collaborative.
