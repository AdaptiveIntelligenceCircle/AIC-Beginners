# AIC-Beginners
A guide for community - second version but for beginners | @AdaptiveIntelligenceCircle 

**Welcome.** This repo is the simplest door into
[Adaptive Intelligence Circle](https://github.com/AdaptiveIntelligenceCircle).

AIC builds **ethical coordination infrastructure**: systems where
*refusal*, *audit*, and *human judgment* sit close to important decisions —
not only as a blog post after launch.

> This page uses plain language.  
> It does **not** replace the Charter, Legal policies, or the Whitepaper.

---

## In one minute

| | |
|--|--|
| **What** | An independent, non-profit-oriented open effort on AI + governance infrastructure |
| **Not** | A UN body, a Big Tech product, a token scheme, or a finished global network |
| **Stage** | **Pre-Covenant** — TestNet and evidence before big claims |
| **You** | Reader, documenter, tester, or careful code contributor |

**Partner ≠ owner.** A meeting, fiscal host, or logo does not mean someone else owns the protocol rules.

---

## Three ideas (core narrative, simple words)

1. **Ethical Kernel** — Important “no” rules should be hard to switch off when pressure is high.  
2. **Human Meaning Network (HMN)** — Some actions must wait for a real human, not a fake “OK” click.  
3. **Third Path** — Not pure state capture, not pure commercial sale of protocol law.

We respect open-source freedom **and** refuse to treat government/public systems as playgrounds for unsupervised agents.

## Contributing (beginner-friendly)

We prefer **clear, small, honest** help:

- Fix typos / improve this Start-Here wording  
- Add glossary entries  
- Test docs on a clean machine and report gaps  
- Careful code only after you understand Deny / NeedHuman norms  

See [06-how-to-contribute.md](./06-how-to-contribute.md).

Unpaid, reputation-oriented collaboration is normal here.  
If you only work for immediate pay, say so upfront — no hard feelings, just a different fit.
